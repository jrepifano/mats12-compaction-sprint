# P39: Is P36's null J-lens reconstruction swap just a size effect, or would a role-chosen slice of the same size move the answer?

Brief: [brief.md](brief.md). Literature: [lit-review.md](lit-review.md), which includes the launching session's dedicated review, whose design changes are all adopted here. Builds directly on P36 ([note](../P36-workspace-binding-causal/note.md), PR #46).

| **Decision it informs** | P36 found that swapping the sparse J-lens reconstruction between role-reversed twins flips 0.1%, while swapping the residual flips 95%. Can that be pitched as evidence that the reconstruction **leaves out** the signal controlling the answer, or does it only show that the reconstruction **is small** (≈ 6% of the twin difference)? **Pitchable:** P36 + P39 become the core of an interp sprint proposal (J-lens monitor test and clamp next). **Size-only:** P36's claim is rewritten as "the reconstruction is small" and the line is not pitched. **Default if never run:** P36 stays unpitchable, because a reviewer would raise exactly this objection (Kawada & Kellis leave it open too). |

## Notes
- **Two verdicts, kept apart.**
  - The brief's question ("could a slice this size move the answer?") is decided by flips at the matched share: O1–O4.
  - The dedicated review's criterion ("the J null is informative only if J's attribution falls clearly below a random slice of the same share") is reported as the labelled J-alignment verdict, and qualifies how O1 is pitched.
  - Both are adopted. They answer different questions: whether small slices can carry the signal, and whether the J slice is worse than chance at carrying it.
- **Order, not role, is what the swap moves** (P36 F1).
  - "Role-chosen" means chosen to carry whatever the twin swap moves.
  - The gradient axis is built aligned to first mention, as primary.
  - The role-averaged version (4b) is expected to cancel across voices and is excluded from the outcome rule, so its null can't be read as "small slices can't carry it". A side agent raised the same point on 2026-10-13.
  - The cross-voice donors test the fitted directions against the order reading directly.
- **Matched arms shrink; they don't swap whole subspaces.** When a direction holds more than s̄ of Δ, the matched patch moves only part of the way along it. The native-size points on each dose curve show what matching hides.
- **Dropped from the first draft:** the i.i.d. Gaussian dictionary. J_rot keeps the J-lens dictionary's geometry and is the stricter control (dedicated review, change 3).
- **Precision and seeds.** Everything is fitted and evaluated in fp32 on bf16 states, as in P36. Seeds: random subspaces 20261013 + draw; covariance draws 20261113 + draw; J_rot 20261040; random atoms 20261050 + draw; random 1-D 20261060 + draw; bootstrap 20261013.
