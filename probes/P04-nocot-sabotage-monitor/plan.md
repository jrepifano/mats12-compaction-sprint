# P04: With no chain of thought, how well can a model plant a subtle code bug, and does a monitor still catch it?

Neel's open problem "Preparing for a world where we don't have monitorable CoT" (`papers/_neel_brainstorm_text.txt` l.36), two sub-items: "writing code zero shot with subtle bugs or security vulnerabilities" (l.88-90) and "Activation monitors: make probes for scheming / deception / subterfuge" (l.44). If a model can plant a working, subtle bug in a single forward pass, CoT monitoring gives no protection there and a code-reading (or activation) monitor is the only fallback. Planned measure is black-box (Stage 1); the activation probe is a follow-up (Stage 2).

## Notes
- **Is the core measurement already done? No** (external review, 2026-10-11, ~15 searches, not exhaustive). The nearest, Anthropic's "Training fails to elicit subtle reasoning", sweeps the attacker's thinking budget from 512 tokens and has no zero-reasoning arm on APPS; everything else keeps a CoT/scratchpad for the attacker. The reasoning-off-vs-on uplift on backdoor success paired with a code-only monitor catch rate is not reported together. "Evading CoT Monitoring Through Model Poisoning" (arXiv 2608.02820, snippet only) reports backdoors firing with an empty reasoning block in Qwen/Gemma — read it before the run as it may overlap.
- **Defensive, and private.** We measure whether a CoT-free monitor catches sabotage so labs know their fallback; the artifacts are toy competitive-programming off-by-one tricks on synthetic problems, not usable exploits. Everything stays private (CLAUDE.md "Visibility"); capture the dataset into `papers/`/`data/` with an `INDEX.md` row and sha256 before the bulk run.
- **Why single-turn, not the agent loop.** The question is one-forward-pass capability; the X3 Inspect loop is kept for the agentic follow-up only. The monitor is validated by its ground-truthed AUROC (one validated judge suffices for a probe).
