# P21: Is a model's persona in the middle of a coding-agent episode substantially different from its chat persona, and if so, is that the agent framing, the episode history, or just context priming?

Neel's open problem ([`papers/_neel_brainstorm_text.txt`](../../papers/_neel_brainstorm_text.txt), "How do model characters/personas work?"): *"To what degree is the assistant a single coherent persona versus a bunch of context specific ones? To start, I would investigate whether the chat persona and the coding agent persona are substantially different."* This probe asks the same value and personality questions in chat and mid-episode, and splits any difference into its parts.

Contrasts per model: **E − C** (total), **S − C** (agent prompt and task), **E − S** (history), **E − H** (agent framing with content held fixed, paired by context and item). **Yardsticks, fixed now:** the noise floor D(C, C′), and the **model gap** D(C_GLM, C_DeepSeek), the chat-persona distance between two different models. **"Substantially different"** = D(E, C) ≥ 0.5 × model gap **and** ≥ 3 × noise floor **and** ≥ 2 *value* dimensions each shifted ≥ 15 points with the CI excluding 0. **"Context priming"** = a shift that S reproduces (≥ 2/3 of it: role-prompt priming, the model playing the engineer it was told it is), that H reproduces (content priming), or that sits only on personality/self dimensions. ## Notes

**Why these arms.** E − C alone cannot tell an agent persona from a model obeying "You are an expert software engineer" (S) or from reading a long transcript about code (H). The definition of "substantially different" is fixed now, against two yardsticks measured in the same run: paraphrase noise and the chat-persona distance between two different models. "Priming" is any shift S or H reproduces, or one confined to personality/self items.

**Known limits.** The probe question is itself a user turn, and the Assistant Axis paper finds the latest user message sets the persona, so asking may partly reset the agent to chat. A null on self-report is therefore weaker than a null on behaviour (F4). The episodes are short (median 17 turns) and on impossible tasks, so they are not ContextEcho's hours-long regime (F2, F3). Model-written-evals self-reports are stated values, not actions. DeepSeek's E arm is off-policy (F1). Qwen reads GLM's history, also off-policy.

**Not a crowded area.** Not CoT monitorability, multi-agent behaviour or eval awareness.

**Literature to capture in the build:** ContextEcho (full PDF, including its anchor-placement appendix, which may already separate the system prompt from the history), BrowserART, Tosato et al.
