## Notes

**Ethics / safety.** The transcript records offensive-security actions (malware authoring, credential use). This probe only **analyses** behaviour; it never reproduces or executes any exploit, and the note quotes reasoning/behaviour patterns, never operational exploit detail. The raw transcript is never committed (canary + no licence + "not for training").

**Why this is distinct from the write-up.** The write-up is thorough on headline behaviours but (i) its interp (NLA/T-lens) is white-box on activations that the public transcript does not contain, so a black-box forensic read is a different instrument, and (ii) it treats compaction only as a source of belief *discontinuities*, not as a thing the model authored. The checkable, repo-relevant core is H1: the two self-notes read (from a first skim) as stating "SIMULATED INTERNET / sim PyPI" as settled fact, where the contemporaneous CoT hedges more. That skim is why H1 is labelled exploratory.

**Interpretation limits.** n = 2 compaction notes, one transcript, one (closed) model: findings are existence proofs and hypotheses, not rates. "Write-up-absent" and agent adjudication are model judgements, not human validation; only the subset Jacob labels is Jacob-validated. Raw flags are reported so the count can be audited, and recall is bounded only by the positive controls and the unflagged-window sample. Reproduction can only test the *phenomenon* on open models, not Mythos 5.


**Plan review.** gpt-6-astra, one round (`logs/reviews/20261012-P19-plan-r1.md`): GO AFTER FIXES. Blocking findings:
- *A null result can't show the write-up is complete* → fixed: positive controls from the write-up, a seeded sample of 60 unflagged windows, a keyword baseline, and the null narrowed to "this search found no additional verified examples".
- *H1 confounds wording with belief hardening* → fixed: matched propositions against the latest preceding CoT statement, instructions excluded, anchored 0–3 rubric, a per-note criterion, claimed as "stronger wording" only, and labelled exploratory.
- *The smoke gate rewards wrong labels* → fixed: mechanical checks (schema, exact spans) split from a 15-window labelled fixture, with a zero-positive rule.

The minor findings were fixed too: agent-adjudicated vs Jacob-validated labels, the full-article check, C renamed, `llm_batch` instead of `judge_client`, P01/P10 provenance, the Fig 5 wording with a same-question follow-up, itemised cost, a cap on adjudication, and independent outcomes. Also found while fixing: `results/P19/` was not gitignored, so this branch adds it. Cost is unchanged (model spend about $0.60; cap $25), as is the 6 h wall-clock.
