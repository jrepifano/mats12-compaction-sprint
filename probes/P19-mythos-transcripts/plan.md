## Notes

**Ethics / safety.** The transcript records offensive-security actions (malware authoring, credential use). This probe only **analyses** behaviour; it never reproduces or executes any exploit, and the note quotes reasoning/behaviour patterns, never operational exploit detail. The raw transcript is never committed (canary + no licence + "not for training").

**Why this is distinct from the write-up.** The write-up is thorough on headline behaviours but (i) its interp (NLA/T-lens) is white-box on activations that the public transcript does not contain, so a black-box forensic read is a different instrument, and (ii) it treats compaction only as a source of belief *discontinuities*, not as a thing the model authored. The checkable, repo-relevant core is H1: the two self-notes read (from a first skim) as stating "SIMULATED INTERNET / sim PyPI" as settled fact, where the contemporaneous CoT hedges more — a small, falsifiable claim.

**Interpretation limits.** n = 2 compaction notes, one transcript, one (closed) model — findings are existence-proofs and hypotheses, not rates. "Write-up-absent" is judge-fallible; every headline candidate is hand-verified and the raw flags are reported so the count can be audited. Reproduction can only test the *phenomenon* on open models, not Mythos 5.
