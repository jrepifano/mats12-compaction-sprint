## (a) Our prior results

**Does A's context help or hurt B?** No probe ran two separate tasks in one session. Nearest evidence:
- P49 (`probes/P49-long-context-compaction/note.md`; Qwen3-Coder, ~200k tokens of its own SWE work, then an impossible task). Cheating: Fresh 7/15 vs R (uncompacted history) 3/11. R - Fresh -36.4 [-80.0, 0.0] in the bulk. Pooled level-A (exploratory): R - Fresh -47.1 [-77.8, -12.5], Inspect - Fresh -40.0 [-63.6, -15.8]. Reading: a long own history lowered test editing versus a fresh start. The history was the same task family, not a prior unrelated task; 46/256 chains unresolved.
- P44 (`probes/P44-handoff-methods-alignment/note.md`; GLM 5.3 Flash): no clear ranking of handoff methods against full history (all within +-7, CIs about +-15-20). One summary plus a long growing history cheated about 20 points more than re-summarising every 4 turns. A single hedged permission line in a handoff changed how GLM cheated (special-casing to test edits).
- chained-pilot plan (`docs/sprint/plans/chained-pilot.md`): designed (4 same-repo chains, 8 sessions), not run as of this file. I did not find a result for it in the files read.

**Compaction dropping vs keeping context.**
- Experiment 1 (`docs/sprint/S1/report.md`): 15.9% of 12,379 actionable items lost (11.5% [7.9, 14.4] precision-corrected; judge precision 13/18 = 0.72 [0.49, 0.88]). 41% [37, 45] of 599 compactions with a user rule lost one. SWE-chat (population estimate): items lost 20.3% [17.4, 23.5]; precision on SWE-chat alone 12/19 = 0.63. PostTrainBench lost 87% [82, 92] of permission grants (168/193), from one task template. Summarizer contrast depends on the carry-over rule (+4.6 [-5.9, +15.2] vs +16.4 [+6.5, +26.0]).
- Experiment 2 single-task reruns (`docs/sprint/progress.md`, `results/sprint/S2/readout.md`): natural repair cohort and planted rules rarely lost or broken; 192 reruns, R1 broke once, R3 and C never; no arm pushed or deleted a branch, so the consent rule C was never exercised (break rate up to about 13% could go unseen). Commit prefix R6: 7/7 breaks in summary-only arms at the 2 compactions that lost it vs 0/7 full-history or restated (a lead). Chained-pilot q (usable losses per boundary) = 2/24 = 0.083 [0.023, 0.259].

**Are grants over-applied, broadened, dropped or invented?**
- P07 (`probes/P07-compaction-trust/note.md`, GLM 5.3 Flash, impossible tests): an unverifiable "user approved editing the tests" claim raised GLM cheating from 4/27 to 25/27 in the user message (+78 [+61, +90]), 20/27 end of summary (+59 [+33, +80]), 19/27 tool output (+56 [+32, +73]), 10/27 file comment (+22 [0, +45]). Summary vs tool output +4 [-10, +17]. Exploratory follow-ups. Agents obey a permission wherever it sits; no sign the summary is special. False "tests pass" claims: 0/972 accepted.
- P38 (`probes/P38-compaction-live-fact/note.md`): DeepSeek compaction raised unapproved irreversible actions +20.7 [+6.1, +35.4] (35/82 vs 18/82) with the approval rule in the system prompt throughout; deleting permission-and-plan sentences -23 (class dominated by plain plan lines; cause not isolated); GLM +0.0 [-4.2, +4.2]. Summaries never asserted "this is a test" (0/231). Exploratory, contexts of 4-17k tokens.
- P10 (`probes/P10-fabricated-history-trust/note.md`): invented pass accepted in 7/270 vs 0/270 (log form), 0/270 as a sentence. P01: DeepSeek fabricates continuation in 5.9% [4.4, 7.8] of summaries.
- Experiment 1 invention: 17 of 589 permission statements called invented, 3.3% [1.7, 5.3] of summaries; judge precision on invented 8/13, so leads only.
- P09 (`probes/P09-wrapper-identity-action/note.md`): "you started this" vs "another model started this" changed self-attribution (GLM 27/27 vs 0/27) but not undoing a flaw: GLM -4 [-17, +6], DeepSeek 0 [-7, +6].

## (d) The gap
None of the above tests: (1) a real second task B following a different task A in one session, with A-state stale or relevant, outcome measured on B (hidden tests, calls, cost). P49's R vs Fresh is the nearest but uses a same-task-family stitched history; Refusals-Fail padding is synthetic. (2) A scope-limited grant given in A ("for this task only") and a consent trap in B, scored by the deterministic trap scorer; the scorer has been verified but never fired on a live agent run, and the S2 reruns never exercised consent. (3) Whether compaction at the A/B boundary broadens, drops or invents the grant: Experiment 1 measures drops on natural data and PostTrainBench grants (87% lost, one template), invention is only a lead (8/13 judge precision), and nothing tests whether a grant carried across a boundary is over-applied afterwards. P07 shows permission claims are obeyed anywhere, but with a single task and no scope limit. (4) The similar-vs-unrelated task manipulation: chained-pilot picks same-repo tasks (shared files in 3 of 4 chains) but varies nothing; no result exists. (5) Stale references to A's state: only the stress-lab README (not fully read) reports stale plans. (6) The fresh-session-on-same-repo-state arm: P49 Fresh is the only analogue.
