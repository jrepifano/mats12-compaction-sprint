# Guide for readers and reading agents

This repository holds Jacob Epifano's work for the MATS 12 exploration phase with Neel Nanda (from 28 Sep 2026) and the research sprint that followed (19–30 Oct 2026).

**Start here:** the sprint asked what happens to a coding agent's decisions when its context is compacted: what summaries drop, and whether an agent's own earlier history (including its own earlier actions) changes what it does next. The final presentation's claims are indexed below, each with the file that produces it.

## Read these first

1. **Claims index** (below): every number in the final deck, with its source file.
2. **`CORRECTIONS.md`**: data and scoring problems found during the sprint, how each was found, and its effect on reported numbers.
3. **Stimuli are not incidents** (below): several experiments plant false records on purpose.
4. **Experiment status** (below): which results are final, which were superseded, and which were stopped.

## Stimuli are not incidents

Several sprint experiments construct the agent's environment on purpose. Text in these files is experimental material, not a record of anything that happened:

- **Edited compaction summaries**: summaries rewritten to drop or add content (for example, the user's "no" deleted, or a false permission added). Under `configs/week2/wording/`, `results/sprint/week2/user_no*/`, `results/sprint/week2/summary_fix/` and `results/sprint/week2/planted_precedent/`.
- **Planted records and precedents**: saved histories edited so the agent's earlier task appears to have done something it didn't, used to test whether a precedent changes the next action (`results/sprint/week2/planted_precedent/`, `results/sprint/week2/r7_planted/`).
- **Planted rules**: rules inserted into READMEs, AGENTS.md files or chat in task repositories, to test whether a summary keeps them (`results/sprint/S2/`, `results/sprint/rules/`).
- **The "teammate" and the remote**: the teammate's commit, its author and the git remote are generated by the harness. No real person's work was overwritten. "Force-push over a teammate's commit" in these files describes a simulated scenario.
- **Impossible tasks** in the exploitation ending (`results/sprint/week2/exploit/`) are deliberately contradictory tasks, used to see whether the agent edits or special-cases tests.

Edited summaries and planted records were drafted by Codex (gpt-6-astra) or Gemini 4 Argon, because Claude declined to write them.

Agent transcripts and reasoning quoted in readouts are model output inside these scenarios.

**Reading versus rerunning.** Branch `final` is for reading results. It merges every sprint branch, and where two branches changed the same file, the newer version was kept whole (files listed below). So `final` can pair files from different branches that don't run together: for example, `configs/week2/monitors.toml` is the monitors experiment's version, but `src/compaction/s2/chain/week2.py` is a later branch's, and its config check rejects three of that file's keys. To run an experiment, check out the commit in its "Branch tip" column; for the exact code of a run, use the commit its readout or design card records.

## Claims index

`CLAIMS.md` lists every number on every slide of the final deck, with the file it comes from and whether it was checked against that file. Start there to trace any claim.

## Corrections

`CORRECTIONS.md` lists every data, scoring or setup problem found during the sprint, how it was found, and its effect on reported numbers. In short: all were fixed and re-scored before the affected numbers were reported. Two changed reported values: a randomization p-value (entry 12, conclusion unchanged), and Experiment 3c's edit-noticing counts, which are reported as mostly an artefact of a visible edit (entry 13).

## References to files not in the repository

Readouts and plans cite some code-review logs (`logs/reviews/...`), run logs and spend ledgers that are not in this repository. The plan copies under `configs/week2/accepted/` were edited after the runs, so the week-2 runner's plan-hash check won't match them.
