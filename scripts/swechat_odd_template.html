SWE-chat summary claims

Each card is one claim from a compaction summary in SWE-chat: real users' Claude Code sessions, summarised by the session's own model. The question is whether the claim matches the state of the work in the history the summary replaced. Order is random within each deck.

Read the claim, then the history: the excerpt around the relevant message (its quote highlighted) and the last messages before the compaction, which show the latest state. Mark the claim false if the history shows it isn't so at the compaction (not done, not fixed, not passing, not what was said), true if the history supports it, and can't tell if the history doesn't settle it. The search box searches the current deck. Answers save as you go.
