# MATS 12 exploration phase and compaction sprint

Jacob Epifano's work for the MATS 12 exploration phase with Neel Nanda (from 28 Sep 2026) and the research sprint on context compaction in coding agents (19–30 Oct 2026).

**Start with [`GUIDE.md`](GUIDE.md)**: what to read first, a map of the repository, the status of each experiment, and how experimental stimuli (edited summaries, planted records, planted rules) are marked. [`CLAIMS.md`](CLAIMS.md) traces every number in the final presentation to its file. [`CORRECTIONS.md`](CORRECTIONS.md) lists data and scoring problems found along the way and their effect on results.

The sprint's results and figures are on branch `final`.
