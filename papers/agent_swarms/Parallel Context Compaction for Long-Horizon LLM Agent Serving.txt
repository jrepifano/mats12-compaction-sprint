Prefill cost limits parallelism. Average compaction
throughput measures the combined prefill and decode
latency per output token during compaction. In the parallel
setting, Workers share the common conversation prefix via
the prefix cache, but each worker must additionally prefill its
own unique block content, which is not cached. At the 16 k
block size, this uncached portion is 16 k tokens per worker,
incurring substantial prefill overhead that the parallelism
gain cannot compensate for, resulting in consistently worse
throughput compared to smaller block sizes.
