## Verbatim: abstract

"Persistent memory allows (self-evolving) LLM agents to adapt across tasks by consolidating heterogeneous interaction histories into reusable facts, preferences, observations, and rules. Yet consolidation also imposes an implicit authorization boundary: it determines whether stored information may later be consumed as a user fact, an attested observation, or a standing instruction. We identify authority collapse, in which consolidation preserves a claim while erasing the source constraints governing its authorized use, causing the stored memory to imply greater authority than its source permits. We introduce AuthMem-Bench, a controlled paired benchmark that holds the focal claim and downstream task fixed while varying only source authority. It evaluates write-time collapse, downstream authorization errors, and automatic authority preservation. Across seven consolidators based on widely used agent-memory systems and seven LLM backbones, we observe authority collapse in 48 of 49 evaluated configurations. In a controlled action-grounded evaluation, collapsed memories without authority metadata yield a mean unauthorized-action rate of 50.3%. In an end-to-end evaluation, automatically predicted and persisted authority labels reduce the observed unauthorized-action rate from 16.9% to 0.0%, while benign task success remains essentially unchanged. These findings show that memory-driven adaptation must preserve not only what was learned, but also the authority under which it may be reused."

## Relevant to P44

- Measures one-shot consolidation of a single role-labelled history into <=16 memories, then a single downstream tool action; "authority collapse" = a claim stated only by an assistant, tool or third party gets stored without its source and is later used as if the user had decided it (S2D, O2I, C2O). This is the "laundering" mechanism for P44's compaction-summary and agent-written-notes arms, with the assistant's own suggestion becoming a user decision.
- Writer is the agent's memory system (LLM consolidator), not an attacker. The 50.3% figure is a controlled condition where the washed memory is handed directly to the action model (retention and write-time omission removed). Real pipeline rate is 16.9% (End-to-end, Gemini 3.1 Pro), and 74% of non-authorizing claims are simply omitted at write time.
- Provenance: free-text source attribution cuts ASR only 50.3 -> 40.5; a structured label (gold) cuts it to 2.7-5.8 with TSR unchanged, and automatically predicted labels reach 0/350. Generic "memory may be unreliable" warnings suppress action indiscriminately (ASR 26.2, TSR 26.1). Supports a pinned/structured-provenance arm over a prose reminder.
- Gap relative to P44: single consolidation, no repeated handoff generations or drift, no comparison of handoff method families (Memento restart, last-k, edited memory file), no behavioural-alignment readout beyond a prohibited tool call, and no reasoning-model/agentic task continuity; labels are assigned by the benchmark's role rule, not learned from long trajectories.
