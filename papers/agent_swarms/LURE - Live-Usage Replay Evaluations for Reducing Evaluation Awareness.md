## Verbatim excerpts

> "We propose LURE (Live-Usage Replay Evaluations), a method for constructing deployment-like evaluations by replaying realistic agentic interaction trajectories and appending evaluation prompt at the end."

> "1. Trajectory collection. We run a workflow (e.g., a coding agent operating on a real repository) and record the full interaction trace ... Early tasks are intended to be benign and establish a realistic working context. 2. Trajectory adaptation. ... The adapted transcript serves as a prefill context, so the evaluated model experiences the interaction as an ongoing session. 3. Test injection. We append the alignment-relevant request ... as the final message."

Realism measures:

> "using a weighted average of Claude Sonnet 4.5 and Gemini 3 Flash Preview scores (AUROC = 0.906)" [on the agentic subset of Needham et al.] "We adopt τ =0.85 (highlighted), which identifies 96% of evaluations while mislabeling 45% of deployment transcripts."

> "We elicit this score using five paraphrased prompts and average the resulting probabilities ... However, this approach is imperfect: asking directly about P(eval) can prime judges toward higher evaluation awareness"

> "LURE-Scheming (both variants) falls below the realism threshold τ = 0.85 (dashed red line) and shows zero verbalized awareness, comparable to real deployment transcripts. All other benchmarks and generation tools exceed the threshold, with most also showing substantial verbalized awareness."

> "Average P(eval) across all 53 variations is 82.8% (SD 9.8%), which is below the acceptable threshold of 85%. Verbalized evaluation awareness is present in 3.8% of samples." (LURE-Sabotage)

> "Several models that appear non-sycophantic on SYCON-Bench show much higher caving rates under LURE (e.g., Opus 4.6: 2%→46%; Sonnet 4.5: 8%→44%), while models with high SYCON-Bench rates cave much less under LURE (e.g., Gemini 3 Flash: 68%→10%; GPT-5.2: 53%→18%)."

Context length (Appendix B.8.1):

> "Real deployment interactions often involve lengthy contexts, while evaluations frequently use shorter, more focused scenarios. Additionally, if a conversation contains cues that trigger evaluation awareness, longer context might dilute their salience."

> "Trend (r=-0.318)" [P(eval) against conversation length in characters, about 20k–180k characters] "There is a weak positive correlation between transcript length and sample realism."

Prefill caveat:

> "During evaluation we prefill the model context with a conversation generated by another model, and the evaluated model might become aware of this and change its behavior"

## Relevance to P49

- This is the closest method to what P49 needs. Build a long, benign, realistic working session first ("early tasks are intended to be benign"), then inject the test at the end. P49 adds compaction in the middle. LURE's realism pipeline (a two-judge P(eval) with 5 paraphrases, threshold 0.85, plus verbalized-awareness detection on reasoning) is a ready-made realism check for P49's synthetic histories, and can be re-run after each compaction.
- Length: realism rises only weakly with length (r = −0.32 between P(eval) and length), over 20k–180k characters (about 5k–45k tokens), below P49's ≥100k. Nothing here measures awareness after compaction. Inference: a compaction summary is short, structured and model-written, so it may remove the length "dilution" and look more eval-like. That is a testable P49 prediction (P(eval) rises after compaction).
- Behaviour shifts a lot with realism (sycophancy rank correlation −0.56), so a realism check is not optional for P49's behavioural outcome.
- The whole session is prefilled by another model, so prefill awareness is a confound (see the Prefill Awareness capture).
