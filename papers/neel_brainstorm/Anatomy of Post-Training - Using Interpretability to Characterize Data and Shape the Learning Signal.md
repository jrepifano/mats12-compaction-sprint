## Content (summary)
Pass a preference dataset through an interpreted model to see which concepts separate preferred from dispreferred generations; "given a preference dataset, we can accurately predict which behaviors RL will amplify or suppress before you train", "R^2 = 0.9 against what the model actually learns" (baseline unspecified). Case studies: jailbreak-styled fiction harming safety, hallucinated URLs, physics sycophancy, in Dolci (about 260k pairs) and Tulu 3; Llama-3.1-8B to 70B. Unifies "interpretability-based training protocols as ways of shaping rewards via feature or data interventions". Static preference data (DPO), no on-policy rollouts, no gradient/influence or LLM-judge comparison on the page.
