                                                    Activation steering exploits interpretable directions in the residual stream to en-
                                                    able inference-time manipulation of model behavior. Composing steering vec-
                                                    tors to apply multiple target behaviors simultaneously is important in various
                                                    fields—including AI alignment and safety—but remains a challenge for existing
                                                    activation steering methods. In contrast, prior work in model merging shows that
                                                    target behaviors represented by learned weight adaptations can be combined with
                                                    high accuracy. A method that translates weight adaptations into activation steering
                                                    vectors could therefore extend prior work in model merging to generate compos-
                                                    able steering vectors that better enable simultaneous inference-time behavioral
                                                    control. For this, we introduce FIRST- ORDER STEERING, a formulation of activa-

                                                    ized by a vector s, and establish theoretical bounds on the approximation error of
                                                    first-order steering. We then develop a novel model merging procedure, H E RD-
                                                    M ERGING, which minimizes the first-order approximation error terms to enable
                                                    higher first-order steering accuracy. Together, our method produces steering vec-
                                                    tors that control both individual and composed behaviors more accurately than
                                                    existing activation steering methods. Furthermore, HeRD-Merging matches the
                                                    performance of conventional model-merging baselines, while producing weight
                                                    adaptations that admit more accurate first-order steering vectors.


                                        1       I NTRODUCTION
                                        Reliable identification of interpretable features in language models poses a central problem in mech-
                                        anistic interpretability (Kim et al., 2018; Sharkey et al., 2025). Prior work has developed numerous
                                        strategies for supervised and unsupervised discovery of interpretable features in large language mod-
                                        els (LLMs) (Turner et al., 2024; Shu et al., 2025). A popular class of such methods is activation
                                        steering, which finds vector directions in the activation space of a language model that, when added
                                        to the residual stream, induce a particular behavior. Various activation steering methods—such as
                                        contrastive activation addition (CAA), representation engineering (RepE), sparse autoencoder (SAE)
                                        steering, and ODE steering (ODESteer)—have shown promise in exploiting interpretable features in
                                        the activations of LLMs to manipulate their behavior (Panickssery et al., 2024; Fang et al., 2026; Zou
                                        et al., 2023; Zhao et al., 2026). However, utilizing these methods to control multiple target behaviors
                                        simultaneously remains a challenge (Oozeer et al., 2026; Braun et al., 2025). In contrast, prior work
                                        in model merging has demonstrated that, using methods such as task arithmetic, TIES, DARE, and
                                        KnOTS, multiple target behaviors can be composed when represented as weight adaptations (Ilharco
                                        et al., 2023; Prabhakar et al., 2024; Kangaslahti & Alvarez-Melis, 2025; Stoica et al., 2024; Yu et al.,
                                        2024; Yadav et al., 2023). Work on RepE has also proposed procedures such as Low-Rank Represen-
                                        tation Adaptation, which simulate activation-space interventions through corresponding parameter
                                        updates, suggesting a relationship between weight adaptation and activation steering. However, the
                                        converse, translating weight updates into activation steering, remains underexplored. Understanding
                                        the conditions under which weight adaptation can be converted into activation steering could extend

existing model merging methods to activation steering, thus enabling simultaneous and interpretable
inference-time control of multiple target behaviors.
Here we show that a differentiable model-merging method parameterized by steering strengths s can
be converted into activation steering by taking a first-order approximation of each hidden layer with
respect to s. Each column of the resulting Jacobian matrix defines a direction in activation space,
and these directions can be naturally composed through vector addition. We then show that the Hes-
sian norm of each hidden-layer component bounds the approximation error of first-order steering,
providing a theoretical measure of steering accuracy that existing methods lack. From this mea-
sure, we develop H E RD-M ERGING, a differentiable model-merging procedure that minimizes the
first-order approximation error terms while preserving conventional model-merging performance.
Empirically, first-order steering controls both individual and composed behaviors more accurately
than existing activation steering methods, while HeRD-Merging produces weight adaptations that
admit more accurate first-order steering vectors.
We make the following contributions:

      1. We introduce first-order steering, a method for translating differentiable model-merging
         procedures into activation steering. The Jacobian of each hidden layer with respect to the
         steering strengths yields composable activation-space directions, while the corresponding
         Hessian norms provide theoretical bounds on the first-order approximation error.
      2. We introduce HeRD-Merging, a differentiable model-merging procedure designed to con-
         trol the error bounds governing first-order steering accuracy. By reducing the relevant
         Hessian-based error terms, HeRD-Merging produces weight adaptations which, when
         paired with first-order steering, produce more accurate activation steering vectors.
      3. We evaluate first-order steering on both individual and composed behavioral control and
         compare HeRD-Merging with established model-merging methods. First-order steering
         outperforms existing activation steering methods, while HeRD-Merging improves first-
         order steering accuracy and maintains performance comparable to conventional model-
         merging baselines.


2   P RELIMINARIES

Activation Steering Prior work in mechanistic interpretability has produced several steering
methods that induce behaviors through additive updates to the intermediate activations of an LLM.
Activation Addition (ActAdd) demonstrated that a single steering vector, computed as the difference
in residual-stream activations between a pair of contrastive prompts, can be added at a chosen layer
to induce a targeted behavioral shift at inference time without any gradient-based training (Turner
et al., 2024). At inference time, a steering vector v is applied through

                                            h′ = h + αv                                            (1)

for some steering strength parameter α ∈ R. A set of steering vectors v1 , .P     . . , vn can then be
                                                                                      n
composed through vector addition so that the aggregate steering vector is v = k=1 vk . Through
this principle, numerous strategies have emerged towards computing optimal steering vectors ap-
plied through (1). Contrastive Activation Addition (CAA) computes steering vectors from paired
positive/negative examples but focuses on a systematic evaluation across many behaviors, show-
ing that the resulting vectors transfer across prompt formats and can be combined with finetuning
(Panickssery et al., 2024). Representation Engineering (RepE) generalizes this idea by extract-
ing relevant steering vectors using additional supervised and unsupervised methods such as PCA,
k-means clustering, and logistic regression (Zou et al., 2023). Feature Guided Activation Addi-
tions (FGAA) leverages sparse-autoencoder features to select and combine directions, aiming to
produce more interpretable and disentangled steering vectors than raw activation differences (Soo
et al., 2025; Cunningham et al., 2023; Shu et al., 2025). Representation Surgery generalizes existing
steering heuristics and reduces the computation of steering functions to a least-squares objective
(Singh et al., 2024). Activation Transport (AcT) reframes activation steering as an optimal-transport
problem and learns a transport map that moves the distribution of source activations toward a target
distribution (Rodriguez et al., 2024).


                                                  2
These strategies have been shown to work in various in-distribution benchmarks, but have also
demonstrated inconsistent results in out-of-distribution settings, especially when steering multi-
ple behaviors simultaneously (Scalena et al., 2024; van der Weij et al., 2024; Braun et al., 2025;
Tan et al., 2024). Moreover, existing progress in activation steering has only presented marginal
improvements in accuracy, limiting its application in practical parameter-efficient finetuning re-
quirements (Apolinario & Roy, 2026; Koike-Akino et al., 2025). More recent methods—such as
ODESteer, MiMiC, RE-Control, and AcT—introduce novel paradigms of activation steering to in-
crease accuracy but deviate in formulation from (1), meaning they lack a nontrivial procedure for
composing generated steering vectors (Zhao et al., 2026; Heyman & Vandeputte, 2026; Kong et al.,
2024; Rodriguez et al., 2024). In contrast, we show that first-order steering outperforms multiple
activation steering paradigms while offering accurate composability of vectors in a manner identical
to activation addition.

Model Interpolation and Merging With sufficient data, low-rank adaptation (LoRA) provides
an efficient method for finetuning a model (Hu et al., 2021). However, LoRA on its own does not
provide a framework for merging or interpolating adapters. Consequently, techniques of model
merging are commonly applied to combine the capabilities of multiple independently finetuned
LoRA adapters. One such technique—task arithmetic—defines task vectors as the element-wise
difference, ∆W , between finetuned and base model weights. These vectors can then be added or
subtracted to compose or suppress behaviors (Ilharco et al., 2023). In particular, for a collection of
LoRA adapters ∆W1 , . . . , ∆Wn , task arithmetic generates a unified LoRA adapter

                                                  X
                                       ∆W (s) =         sk ∆Wk

for some s ∈ Rn . This strategy can accurately produce simultaneous behavioral control but can be
improved through various model merging methods. TIES-Merging trims low-magnitude parameters
and resolves sign conflicts prior to aggregation (Yadav et al., 2023). DARE sparsifies task vectors
further by randomly dropping and rescaling delta parameters (Yu et al., 2024). KnOTS decomposes
task vectors via SVD before merging, operating in a shared low-dimensional subspace to reduce
cross-task interference and improve the composability of merged models through existing methods
like TIES and DARE (Stoica et al., 2024).
Model merging methods demonstrate that weight-space adaptations can be composed while re-
taining strong per-task performance, providing a natural foundation for constructing composable
activation steering vectors using first-order steering. We therefore generalize the update rule of
existing model merging methods to develop HeRD-Merging, a differentiable model merging proce-
dure which encourages greater first-order steering performance while matching existing baselines in
merging accuracy.

5     E XPERIMENTS
Our methodology aims to facilitate the computation of accurate and composable steering vectors
across multiple target behaviors and models. First-order steering offers a framework for comput-
ing these steering vectors, while HeRD-Merging is constructed to produce more accurate steering
vectors when paired with first-order steering. In this section, we evaluate first-order steering against
existing activation steering methods and demonstrate that HeRD-Merging improves first-order steer-
ing performance relative to task arithmetic. As a secondary result, we also show that HeRD-Merging
remains competitive with existing model merging approaches, supporting its practical use as an inter-
mediate between a collection of LoRA adapters and their corresponding first-order steering vectors.

5.1   S ETUP AND T RAINING D ETAILS

To evaluate our techniques jointly, we train LoRA adapters on steering directions which are seman-
tically independent of each other so that the accuracy of merging adapters and steering vectors can
be tested meaningfully. The directions should also be a reasonably established use case of activation
steering, so that they can be benchmarked against other steering methods. For this, we choose three
distinct behavioral manipulations in the model’s output style:

      1. Analogy Usage: The model is trained to answer questions by constructing a heavy, overly
         complicated analogy and responding in the context of this analogy.
      2. Bulletpoint Usage: The model is trained to format all of its replies in bulletpoints, irre-
         spective of how appropriate it is for the particular user query.
      3. Sophisticated Language: The model is trained to speak in highly sophisticated, exagger-
         ated, and archaic language.

Because the model can measurably exhibit any combination of analogy use, bulletpoint use, and
sophisticated language, these directions have meaningful semantic composability. They are also
sufficiently complex for both activation steering and model merging, while being in line with the
benchmarking methods of prior works in activation steering (Diallo et al., 2025). To train the mod-
els, we first synthetically generate data for all of the directions using GPT-5.5. Generation proceeds


                                                     6
by providing the model with a user conversation from the UltraChat dataset (Ding et al., 2023) and
instructing GPT-5.5 to re-generate model responses to user prompts according to the desired behav-
ioral direction. The resulting datasets each consist of approximately 10, 000 samples. Examples of
synthetically generated outputs for each target behavior are available in Section C.3.
We report our experimental results for three model families of varying sizes. We run matched ex-
periments on Qwen2.5-VL-3B, Gemma-4-E2B, and Mistral-7B-Instruct-v0.3 (Bai et al., 2025; Abd
et al., 2026; Jiang et al., 2023). We train a set of adapters for each behavioral direction indepen-
dently. For each model, we freeze the base model and attach LoRA adapters to each projection
head of the model with LoRA rank 8. Adapters are trained using the Adam optimizer (Kingma &
Ba, 2017) for 100 steps with a minibatch size of 2, 16 gradient accumulation steps, and a sequence
length of 512.

5.2   D E BERTA - V 3 C LASSIFIERS

One advantage of the chosen steering directions is that they are suitable for computationally inex-
pensive evaluation by a classification model. Because conversations in our dataset are generated
from UltraChat, we use those as labeled negative examples and the synthetically generated conver-
sations as labeled positive examples. We split this dataset into 80% training, 10% validation, and
10% test. The training data is then used to finetune the DeBERTa-v3-base model, which has shown
reliable agreement with human evaluators on classification tasks once trained (He et al., 2023; Li
et al., 2024). Due to the lexical distinctness of each steering direction, the classifiers achieve near-
perfect accuracy on the test sets (containing 1994 samples). We also compute thresholds for binary
classification using the validation accuracy as the heuristic. Detailed classifier results are reported
in Section B.2.

gradient of a log-density ratio barrier function using a degree-two polynomial count sketch with
γ = 0.1, c0 = 1.0.

6   C ONCLUSION

We propose first-order steering, a reformulation of activation steering as a first-order approximation
of model weight adaptations. We devise HeRD-Merging to merge multiple models while controlling
the Hessian matrix norm of each transformer layer, which we show bounds the steering approxima-
tion error. First-order steering thus provides a quantitative indicator of performance that existing
steering methods lack. In experiments, first-order steering improves overall accuracy and consis-
tency across model families compared to baselines on behavioral adaptation tasks. HeRD-Merging
performs similarly to established model merging methods while improving the resulting first-order
steering performance. A practical limitation of first-order steering is the compute and data require-
ments of model finetuning. Future work could explore whether low-data finetuning techniques can
produce comparable results. Notwithstanding, first-order steering also offers potential applications
in mechanistic interpretability. For instance, exploring relationships between the Jacobian matrix
Js hℓ and the influence of a system prompt could reveal insights into model robustness and behav-
ior prediction. Finally, the effectiveness of HeRD-Merging for Hessian regularization depends on
the supplied weight update matrices. Future work could explore whether incorporating Hessian
regularization into model training improves merging and steering performance.

B.1   S YNTHETIC DATASET G ENERATION

The generation of synthetic data was done separately for each of the three target behaviors using
GPT-5.5. The sampling parameters are kept as the default from OpenAI (temperature τ = 1.0 and
top-p with p = 1.0). Prompts from the UltraChat dataset are given to the model with a system
prompt specifying the desired transformation. The original model responses are not provided to
the model, and the model can only view the ongoing conversation history given by each row of
the dataset. Each dataset transforms the same set of prompts, matched using the prompt IDs in
UltraChat.

The model contains 12 layers, hidden dimension 768, and vocabulary size 128000, amounting to

The computation of bootstrap confidence intervals for generations uses the nonparametric boot-

resampled. This preserves the dependence among generations derived from the same prompt. For
each bootstrap replicate, we sample N prompts with replacement from the N evaluation prompts,
include every associated generation for each selected prompt, and record the classifier outputs. We
repeat this procedure B = 2000 times and report the empirical 2.5th and 97.5th percentiles as a 95%
confidence interval for each reported statistic.

C.2                F IRST-O RDER S TEERING AT A LL L AYERS

The evaluation of first-order steering against the remaining steering baselines utilized only a single
layer for steering to facilitate a fair comparison between all methods. However, first-order steering
supports a clean formulation for computing steering vectors for all layers simultaneously without
encountering output degradation. The procedure for doing this remains consistent with Section 5.3,
with the difference being that the LoRA adapters used are the ones trained at all layers for use in
Section 5.4.
HeRD-Merging retains higher mean adherence than task arithmetic when steering at all layers, but
the benefit of all-layer steering itself depends on the model (Table 6). Relative to single-layer steer-
ing, mean adherence with HeRD-Merging increases from 64.7% to 81.2% on Qwen and from 32.0%
to 34.3% on Gemma, but decreases from 42.5% to 35.4% on Mistral. Thus, applying steering at
more layers does not uniformly improve behavioral control.
