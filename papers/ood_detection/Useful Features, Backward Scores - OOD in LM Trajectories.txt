                                                   Useful Features, Backward Scores:

                                                                                   Abstract
                                                  Out-of-distribution (OOD) detectors prioritize inputs for closer inspection. Yet
                                              features that distinguish input groups need not yield a useful anomaly ranking. We
                                              analyze this gap in language-model trajectories under text-length control and fixed
                                              score directions. On Spam development data, an input adaptation of D2 HScore
                                              falls from raw AUROC 0.919 to 0.530 after length matching. On length-matched,
                                              held-out HateSpeech inputs, the same features yield AUROC 0.644 for a labeled
                                              linear classifier but 0.444 for an ID-fitted distance score. ToxicChat shows the same
                                              contrast. Feature-selection and backbone controls retain the main reversal pattern.
                                              Frozen Civil Comments and TweetEval irony tests also reverse (0.467 and 0.435),
                                              extending the finding beyond toxicity. In these contrasts, anomalous groups have
                                              farther centers but tighter spread. A labeled, fixed-center feature-space intervention
                                              changes rankings: equalizing spread helps some tasks and harms others. OOD
                                              evaluation must check the chosen score’s ranking even when its features distinguish
                                              the classes.


                                        1    Introduction
                                        A distance-based toxicity detector uses non-toxic examples as its reference and ranks
                                        inputs for closer inspection by their distance from that reference. If toxic inputs receive
                                        lower scores, they fall behind non-toxic ones in that ranking, even when the features
                                        distinguish the two groups. This makes the score itself an evaluation target: informative
                                        features alone do not establish useful detection. We study this gap for language-model
                                        trajectories, which summarize changes in internal representations across layers. We
                                        test whether apparent detection survives length matching and whether the predefined
                                        distance score ranks the designated OOD inputs in the intended direction.
                                            Length is the first problem. On Spam development data, Input-D2 H gives raw AU-
                                        ROC 0.919, but only 0.530 after matching normal and anomalous inputs within shared
                                        token-length bins (Table 1). This score adapts D2 HScore from generated responses to
                                        input tokens. Other scores respond differently to matching, changing which methods
                                        appear useful. Length control therefore changes the assessment of these input-domain
                                        scores.
                                            After matching, a second problem remains. On held-out HateSpeech inputs, a linear

us ask why features that distinguish the classes give the wrong distance ranking.
    Why does the distance score fail? On ToxicChat and HateSpeech, the out-of-
distribution (OOD) center is farther from the ID reference, but the OOD group is tighter.
The detector scores individual points, not group centers: a tight group can have smaller
distances for many of its members (Figure 1). We test spread’s role by expanding or
shrinking OOD feature points at fixed centers. Rankings change in both directions, and
equalizing spread does not consistently repair them.
    Our analysis of fixed trajectory scores does not propose a new detector. Length
matching, same-feature readouts and spread tests at fixed centers expose when features
and rankings disagree. New-data tests bound the result. This extends backward-score
analysis [Nalisnick et al., 2019] to LM trajectories and makes score ordering a separate
evaluation target.


2                            Representations and Scores
Here OOD means different from the deployment reference, not absent from the model’s
pretraining data. ToxicChat uses non-toxic conversations as ID and toxic conversations
as OOD; HateSpeech, Spam and Jailbreak use their corresponding normal/anomalous
labels. The reference geometry is fit on ID examples only. We test whether the score

     Each input becomes a point whose coordinates summarize its trajectory. Four
features describe changes in direction between adjacent layers (alignment and churn).
Two track how variation across token positions changes across layers. Two compare
the directions and relative sizes of attention and multilayer perceptron (MLP) outputs.
One measures alignment at a fixed early layer. These nine features were chosen from 21
candidates using exploratory development labels; Appendix D gives every definition and
selection decision. Let Z(x) denote the selected coordinates standardized using only ID
references, with reference mean µ and sample covariance Σ. The fixed trajectory radius
is
             p
  straj (x) = q(Z(x)),         q(z) = (z − µ)⊤ P (z − µ), P = (Σ + 10−3 I)−1 . (1)

The detector treats larger radius as more anomalous. AUROC is the probability that
an OOD example receives a higher score than an ID example, counting ties as one
half. A value of 0.5 is chance; below 0.5, the ranking is reversed. Any strictly in-
creasing transformation of radius preserves AUROC: the problem is the ordering, not
the numerical scale. Choosing the score sign on labeled validation data makes the
method semi-supervised. Choosing it on test labels measures how well the classes can
be separated, but does not evaluate the predefined detector (Appendix C).


3     Analysis Design
3.1    Tasks and model
The development suite contains ToxicChat [Lin et al., 2023], Jailbreak [jackhhao, n.d.],
the binary Tweets Hate Speech Detection collection [tweets-hate-speech-detection,
n.d.], and SMS Spam [Almeida et al., 2011]. Qwen3-0.6B is the primary backbone;
four additional backbones span 360M–4B parameters and four model families in total.
Appendix F gives model details, partitions and source limitations.

3.2    Development and confirmation sets
Each task has disjoint ID-reference, validation, development and confirmation partitions.
The 200–250 ID references alone fit standardization and precision. Feature selection uses
200 development examples per class, greedily deleting from 21 candidates to maximize
class separation while allowing either score sign. The search uses development labels to
choose a sign; evaluation keeps the sign fixed. The complete path and tie rule appear in
Appendix D.
    The representation and extractor are frozen before confirmation analysis. Trajectory
analysis excludes inputs shorter than six tokens; the development comparison scores
retain them. All inputs are capped at 512 tokens. Appendix F documents class counts
and extraction checks.




                                           3
3.3    Length-matched evaluation
Input length differs sharply between several classes. We group inputs into shared token-
length bins and sample equal ID and OOD counts within each bin containing both
classes. We compute AUROC over all retained examples, then average across the fixed
matching seeds. Labels determine which examples to retain, not their scores or sign.
Matching balances counts within bins, not exact lengths, and changes the evaluated
population. In Table 1, each method is matched on its own valid inputs, so subsets
can differ across methods. Appendix F gives the bin rule, seeds and retained counts;
Appendix G tests sensitivity to bin count.

3.4    Readouts and comparison scores
Same-feature readouts. One L2-regularized logistic classifier is trained jointly on
length-matched ToxicChat and HateSpeech development inputs, using the nine ID-
standardized coordinates after reference centering. A scalar control instead applies
logistic regression to a cubic-spline transformation of radius with eight ID-reference
quantile knots and linear extrapolation. Both use identical training rows, labels and
weights, with equal weight for each source–class group and fixed regularization (C = 1).
Source training is matched with seed 42. We evaluate their decision scores on disjoint
confirmation inputs, with no evaluation-set tuning.

Length-comparison scores. The length comparison adds three input-domain adapta-
tions: CED-1C uses one-class oracle/auxiliary distances [Lee et al., 2024], Input-D2 H
uses dispersion and attention-guided drift [Ding et al., 2025], and Input-TV uses lay-
erwise ID-distance volatility [Wang et al., 2024]. Appendix E specifies their changed
source settings, equations and fixed hyperparameters. Each score keeps its predefined
OOD direction.

3.5    Feature-selection controls and prospective tests
Four leave-one-task-out (LOTO) folds rerun the full 21-to-3 elimination path on three
development tasks, then evaluate the excluded task with larger radius fixed as OOD. Its
labels do not influence subset search, although candidate design remains historical. A
retrospective cohort includes every cache meeting the recorded schema, ID-reference
and class-count criteria: 11 evaluations, one sharing the development source. Cross-
model analysis reuses the four task contrasts.
    Civil Comments [Borkan et al., 2019] defines ID as toxicity ≤ 0.10 and OOD as
toxicity ≥ 0.80. An initial frozen validation study was inconclusive. A separate protocol
then fixed the features, orientation, references and evaluation quotas before official-test
feature extraction. We report both stages without pooling; Appendix B records their full
chronology and protocol hashes.

survive comparison within shared length ranges. CED-1C drops less and retains signal
on Spam; Input-TV improves on some tasks. Length matching changes which scores
appear useful.

4.2   Useful features, backward scores
A linear classifier trained on ToxicChat and HateSpeech development labels gives
matched AUROCs 0.656 and 0.644 on held-out examples from those sources. With the
same nine features and evaluation rows, distance from the ID reference gives 0.457 and
0.444. Figure 1 shows the HateSpeech example: the features support classification, but
their distance score ranks the anomalous class backward.
    A nonlinear readout of radius trained on the same labeled rows and weights reaches
0.537 and 0.547 on the two confirmation tasks, below the vector readout’s point esti-
mates.

4.3     Does the reversal persist?
4.3.1   Does reversal survive feature and metric choices?
The reversal could depend on choosing features with development labels. Rerunning
subset selection while excluding each evaluation task preserves all 4/4 AUROC di-
rections (Table 2). ToxicChat and HateSpeech remain below chance; Jailbreak and
Spam remain above it. The excluded task’s labels do not drive selection, although the
candidate features were designed on the original suite.
    All-candidate and fixed-sign checks preserve the point-estimate directions, and
ToxicChat and HateSpeech remain below chance under every tested precision geometry.
Two fixed-sign intervals cross chance; Jailbreak confirmation can reverse under metric
changes. Appendices B and G give the full controls and uncertainty.

4.3.2   Does the pattern transfer across backbones?
Five backbones spanning four model families keep AUROC on the same side of chance
in 19/20 comparisons. The exception is SmolLM2 ToxicChat, whose AUROC is at
chance (Appendix Table 5). These checks reuse the same task contrasts and therefore
test backbone sensitivity, not independent task replication.

4.3.3   Does reversal persist on new data?
Disjoint same-source confirmation. Held-out examples test whether the original
samples drove the result. All four AUROC point estimates retain their development
directions, but the rankings are weaker. The intervals cross chance for ToxicChat and
Jailbreak, making these two confirmations inconclusive (Appendix Tables 3 and 20).

prediction for every OOD class.

4.4    How does spread affect the score?
The reversals are not explained by a nearer OOD center. All four OOD centers are farther
from the reference than their ID counterparts on both development and confirmation
splits. ToxicChat and HateSpeech instead have smaller within-group spread (Figure 1C).
The score measures each point’s distance from the reference, not its distance from its
own group center.
    A tight cluster and a wide cluster can have the same center but different distances
from the reference. To separate these effects, we write the mean squared distance as a
center term plus a spread term. For an evaluation group G, let νG be its center (centroid)
and CG its covariance, computed with the group size as the divisor. The standard
mean-square identity gives:

The first term measures the group center’s distance from the reference; the second
measures spread around that group center. Subtracting ID from OOD gives ∆rad =
∆cent + ∆disp . A farther OOD center can coexist with smaller mean squared distances
if the OOD points cluster tightly enough. The reference geometry stays fixed, and no
Gaussian class assumption is needed. Appendix C gives the derivation.
     Across all eight task–split comparisons, the sign of the mean squared-radius dif-
ference agrees with whether AUROC is above or below chance (Figure 3). This is

squared radius can order the groups differently. We now test spread’s effect on the
individual rankings directly.

Scales α > 1 spread the OOD points apart; scales α < 1 pull them together. The OOD

5       Related Work

Sun et al., 2022]; CED adds target–oracle and target–auxiliary relations [Lee et al.,

location, variance and curvature. Background statistics and complexity provide further
explanations [Ren et al., 2019, Serrà et al., 2020]. We examine ranking failure in LM
trajectories, separating length sensitivity from reversal after matching.

6       Discussion and Limitations
The evaluation lesson extends beyond this radius: an OOD claim concerns the ordering
produced by a prespecified score, not just information in its features. Our analysis
exposes two distinct ways such a claim can be overstated. Compare raw and length-
matched performance to see whether apparent success survives among texts of similar
length. Then evaluate the score itself: useful class information and a farther OOD


                                                          9
center do not guarantee the intended ranking. The spread intervention shows why
correcting the mean squared distance is insufficient. Ranking depends on individual
score comparisons.
    ID-only scores remain useful on other task contrasts. Alternative readouts help
some cases without a general repair (Appendices B.1 and G.2). Retrospective unit
normalization of ID-centered features, with a new ID-only reference fit, raises Civil
test matched AUROC from 0.467 to 0.521 [0.497, 0.545]; the paired change is +0.053
[+0.023, +0.084]. The normalized interval still includes chance, so this fixed control
does not establish above-chance recovery.

Limitations. We diagnose score behavior without identifying why classes contract.
Linguistic composition, collection source and model behavior remain possible causes;
jailbreak labels in particular differ in source composition. Candidate-feature design is
historical, the cache cohort is retrospective, and backbone checks reuse the original task
contrasts.
    Matching retains only shared length bins, leaving small samples for some tasks.
Intervals condition on feature design and assume independent rows rather than source
clusters; intervention intervals also hold the reference fit fixed. The feature-space
intervention uses evaluation labels and may leave the set of realizable text features.
Results cover the tested trajectory probe in 360M–4B models, not frontier systems or
all LM representations.

Conclusion. Length matching can remove apparent success while leaving backward
rankings. The same trajectory features can support within-source classification and
produce below-chance distance rankings. Fixed-center spread interventions connect
this mismatch to the score’s geometry. Our analysis makes the scoring rule a separate
evaluation target: test its intended ranking under length control instead of inferring
detection from useful features alone.


Ethics Statement
OOD detectors can affect moderation, abstention, and access decisions. A reversing
score can create false reassurance or disproportionate false positives. We release selected
numeric features and per-sample scores without text or source identifiers, distinguish
supervised calibration from one-class detection, and recommend deployment only after
task-representative validation. Source datasets include toxic and hateful language; we
release no new examples.

C      Score Orientation and Mean Squared Radius
Proposition C.1 (Centroid–dispersion decomposition). For a standardized random
vector Z, a fixed reference mean µ and P ⪰ 0, Equation 2 holds for any group with
finite second moments. Its empirical form computes evaluation covariance with the
group size as the divisor, regardless of the reference covariance estimator.
Proof. Write Z − µ = (Z − νG ) + (νG − µ), expand the quadratic and take expectations.
The cross term vanishes because EG [Z −νG ] = 0; the centered quadratic has expectation
tr(P CG ).
Definition C.2 (Fixed-orientation detection and separability). For independent XID
and XOOD , define
            A(s) = Pr[s(XOOD ) > s(XID )] + 21 Pr[s(XOOD ) = s(XID )].                (4)
Fixed-orientation detection evaluates the predefined s using A(s). Allowing either score
sign measures class separation as S(s) = max{A(s), A(−s)}.
Proposition C.3 (Orientation is part of the detector). For every scalar score, A(−s) =
1 − A(s) and S(s) = 12 + |A(s) − 21 |. Choosing between s and −s with evaluation
labels measures separability. It cannot evaluate the predefined detector.
Proof. Negation exchanges greater-than and less-than events while preserving ties.
Their probabilities sum to one, with half of each tie assigned to either AUROC.

E.1    CED-1C
For target embedding e(x), CED first selects the three nearest ID oracle examples. For
each oracle, it ranks ID auxiliary candidates by cosine opposition between e(x) − e(a)
and e(x) − e(o), keeps the 100 least similar, and selects the five farthest. Text pairs are
concatenated as “target. auxiliary,” matching the released implementation. Let Dc (z)
be squared Mahalanobis distance to the selected class reference. Our OOD-positive
adaptation is

    sCED (x) = Dc (x) − 0.7 Eo [Dc (o)] + 0.2 Eo,a [Dc (x ⊕ a) − Dc (o ⊕ a)] .        (14)

The source implementation uses negative squared distance as ID confidence; this equa-
tion is its OOD-oriented negation. We change the source setting to one ID class,
replace RoBERTa/OpenAI embeddings with Qwen, and use final-token decoder pooling.
The source paper and code are available at https://aclanthology.org/2024.
findings-emnlp.874/ and https://github.com/MLAI-Yonsei/CED.

F       Data and Reproducibility
Reference scaling. Trajectory radius uses StandardScaler fitted on ID references
only: subtract each coordinate’s mean and divide by its population standard deviation,
using scale one for constant coordinates. The sample covariance and ridge in Equation 1
apply after this transformation.

Confirmation and matching. Confirmation starts after the first 200 test examples per
class, with equal quotas set by the smaller remainder. Filtering can leave unequal counts.
The six-token cutoff is an extraction criterion, not a requirement of the layer-third
definitions. Main-analysis bins use pooled linear percentiles and half-open intervals,
with one added to the final edge. Equal lengths stay together; bins missing either class
are skipped. Each seed initializes one generator used across bins. Each backbone uses
its own truncated token counts, so matched rows can differ. Appendix H gives the
separate comparison protocols.
    We divide pooled token counts into B = min(10, max(1, ⌊min(nID , nOOD )/10⌋))
equal-frequency bins. Development uses ten bins; confirmation uses nine for Tox-
icChat, five for Jailbreak, and ten otherwise. Each matched subset combines the
retained bins. We compute AUROC on the whole subset, then average across seeds
{42, 123, 456, 789, 1337}. Trajectory-radius development retains 246, 172, 364, and
118 total examples for ToxicChat, Jailbreak, HateSpeech and Spam, respectively.
